# Command-line cases shared by args.bats and Args.Tests.ps1
# (docs/Conventions.md section 3.3). One case per line:
#   exit|stream|text|arguments
# stream is out or err: the stream that must contain text. Arguments are
# split at spaces. @ROOT@, @ETC@ and @SELF@ are replaced by the test's data
# root, configuration folder and the name the runner is started by. Only -r,
# -k, -u, -V, -h and -P are spelled the same by both runners, so text here
# never names another option at the start of a match.
#
# Usage errors: the name, then one line naming what is wrong, an optional fix
# line, then a pointer to help.
